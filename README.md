# ljubijankic-tui-web

Terminal-style portfolio built with Vue 3 and WebTUI. See [docs/PROPOSAL.md](docs/PROPOSAL.md) and [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

## Setup

```sh
npm install
npm run dev
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Type-check and production build |
| `npm run test:unit` | Vitest |
| `npm run lint` | oxlint + ESLint (with `--fix`) |
| `npm run format` | Prettier on `src/` |
